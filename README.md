## 📖 Overview

Businesses often treat all customers the same, wasting marketing resources and missing high-value customers. This project uses **K-Means Clustering** to segment 300 customers based on:

- Annual Income
- Spending Score
- Age, Purchase Frequency, Membership Years

The result: **5 distinct customer segments** with targeted marketing strategies for each.

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- pip

### Option 1 — One Command (Recommended)
```bash
git clone https://github.com/YOUR_USERNAME/customer-segmentation.git
cd customer-segmentation
python run_all.py
```
This will automatically:
1. Install required libraries
2. Generate the dataset
3. Run K-Means clustering
4. Save 7 charts to `output_plots/`

## ⚙️ Algorithm

```
1. Load data (CSV / synthetic)
2. Preprocess: encode gender (0/1), StandardScaler normalization
3. Elbow Method: plot WCSS for K = 2 to 11
4. Silhouette Score: validate best K
5. K-Means++ initialization
6. E-Step: assign each point to nearest centroid
7. M-Step: recompute centroids as cluster means
8. Repeat until convergence
9. Label clusters by business meaning
10. Visualize & export
```

**WCSS Formula:**
```
WCSS = Σᵢ Σₓ∈Cᵢ ‖x − μᵢ‖²
```
